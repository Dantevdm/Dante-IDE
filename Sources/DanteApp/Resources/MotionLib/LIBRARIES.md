# Motion libraries

Bundled with Dante for motion scenes, served under `_dante/lib/` with an import map
(`MotionLibrary` in DanteKit). Only the files scenes need are kept; type declarations are left out.

| Library | Version | Licence | Folder |
| --- | --- | --- | --- |
| three.js (build plus selected examples/jsm addons) | 0.186.1 | MIT | three/ |
| hairline (dist/index.js) | 0.3.0 | MIT | hairline/ |
| @dicebear/core | 9.4.3 | MIT | dicebear/core/ |
| @dicebear/open-peeps | 9.4.2 | MIT code; Open Peeps drawings CC0 | dicebear/open-peeps/ |

Each folder keeps its LICENSE. GSAP is deliberately absent: its standard licence excludes
software that lets people make animations.
