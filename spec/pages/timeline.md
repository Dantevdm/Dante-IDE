# History (Ship › History)

History is the project's history in one stream: commits, the agent's conversations, test runs and CI.

## Shows
- Events newest first: commits, releases, agent conversations, test runs and CI runs, each with its time.
- A filter by kind.

## Actions
- Filter by kind; show more.
- Open a commit's diff, a conversation, a test run or a CI run.

## States
- Reading the history: a progress line while it loads.

## Acceptance
- Events from every source interleave by time.
