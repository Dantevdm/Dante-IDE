# Setup (Agents › Setup)

Setup is how the agents are set up for this project: skills, memory files, connectors, plugins, permissions and recent conversations.

## Highlights
- It suggests skills worth adding for the project and drafts them.

## Shows
- Skills: the project's and the user's, with suggestions worth adding and when they were last reviewed.
- Memory: the CLAUDE.md files and what each costs per message.
- Connectors (MCP servers), plugins installed and available, permissions (allow and deny rules).
- Recent conversations.

## Actions
- Draft a skill with the agent; open or move a skill to the Trash.
- Write or tighten a memory file with the agent.
- Install a plugin (asks first); open settings.json.
- Resume a recent conversation.

## Acceptance
- Nothing is installed or deleted without a confirmation.
