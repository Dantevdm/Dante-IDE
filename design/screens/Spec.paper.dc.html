Transfer limits

Each account may send at most a set amount per UTC day, so a leaked key or a bug can only move so much money.

1. Rules

The default limit is 5,000.00 in the account’s currency, stored as 500,000 minor units. An account can carry its own limit in account_limits, which replaces the default rather than adding to it.

The check counts outbound transfers created since 00:00 UTC. It must run after the per-account lock is taken, or two transfers arriving together could both pass.

2. Acceptance criteria

Status is live from the last test run.

AC-1Transfers under the daily limit go through.Passing
AC-2A transfer that crosses the limit is rejected with 409.Passing
AC-3The limit resets at 00:00 UTC.Passing
AC-4Concurrent transfers cannot exceed the limit together.Failing
AC-5Each rejection writes an audit entry.No tests

3. Open questions

Should incoming transfers raise the limit for the rest of the day? For now they don’t, which is the simpler rule.
